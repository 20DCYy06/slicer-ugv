# 视觉吸嘴校准与手动升降 · 2026-11-21

- 从 `e003604` 开始，在独立短期分支和独立 Catkin 目录工作。原车端检出有无 RTK 速度参数编辑与未跟踪的 `.vscode/`。当前整车安装为 `slicer_noetic_c30d_v16`。
- 依据现场标注图，把红色 X 的交点换算到 640×480 原始画面，保存为约 `[389, 375]` 的固定吸嘴红点。该值属于本车相机，保存在 `~/.config/slicer_visual_grasp/config.json`。可在界面用“校准红点”点选微调。其余车端相机和抓取参数沿用现有配置。
- 默认预览增加“启用操作”，原 `--run` 入口继续可用。新增上升、下降点动。现场确认 Y 为上升，沿用共享舵机配置的 2100/900/1500 µs。松手、离开按钮或失焦即取消点动，默认最长 0.3 秒。升降与抓取由同一动作线程入口串行执行。

参数与操作见 [视觉抓取说明](../../src/slicer_visual_grasp/README.md)。部署与现场验收另记于本文件。
