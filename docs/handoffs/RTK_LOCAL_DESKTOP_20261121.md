# RTK 本地桌面 · 2026-11-21

- 从 `ca0d889` 在独立工作树实现。交付位于 `tools/rtk_desktop_ui.sh` 和 `tools/rtk/desktop/`，不需要重建 Catkin。源码和配置保留既有定位、配准、地理目标、V1/V2、底盘、Guard 与 Mux 链路。
- 左右窗口从 Qt 主屏读取几何并按 75% / 25% 分屏。新鲜的全局代价地图优先决定固定坐标系，地图只发送增量时使用活动 planner 的配置。看板按 GNSS、配准、真实目标及 odom 数据刷新。
- RViz 有两个专用输入话题。Waypoint 在地面平面取点，并打印 WGS84 和局部坐标。2D Nav Goal 使用现有 `/ugv/move_base` Action。已有目标、空地任务、Mux hold、急停和配准动作有优先权。
- 通过 7 项单元测试。在 1920×1080 的独立 Xvfb 和 loopback ROS master 上实测窗口几何、真实鼠标事件、`odom` 与 `map` 目标、WGS84 与 `odom` 打点、旧代价地图优先，以及启动脚本正常退出。
- 右栏正文显式设置为 15–22 pt。验证 300×660 和 480×1080 两种看板尺寸的配准和导航页面无裁切。
- 操作见 [整车操作手册](../OPERATIONS.md#rtk-本地分屏桌面)。关闭新桌面即可结束外挂，原有 RViz 预设仍可按原入口启动。实车导航未用于此轮开发测试。
