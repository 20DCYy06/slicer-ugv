# RTK A/B 抓取弹窗与 C30D v1.9

A 的规划来自 `fix/rtk-navigation-stability`（`24a6a0a`），B 来自 `nav/continuity-cost`（`b4e3dbe`）。二者从 `93ccd8c` 分出，分别对应 PR #11、#13。现场 `current` 是独立部署的 `20261125-c30d-front-pwm-v19`（`13e0afb`）。原 A、B 的安装配套 v1.7。本任务只移植现场 v1.9 配套的 `d5311ee`、`13e0afb` 改动，硬件锁定 `0373548750bb3daf7332936652f2c5bb78cb89c7`，两套规划代码各自保留。

## 操作

从所选候选发布的车端桌面终端启动，切换前在原界面结束任务并停止原进程。

```bash
BASE="$HOME/workspace/slicer"
ID=20261126-rtk-a-grasp-v19-rc1
# ID=20261126-rtk-b-grasp-v19-rc1
cd "$BASE/releases/$ID/src/slicer-ugv"
SLICER_RUNTIME_DIR="$BASE/data/$ID" ./tools/rtk_desktop_ui.sh
```

1. 导航空闲且停稳后点击主界面的 **抓取**。桌面确认停车并交接串口，打开原视觉弹窗。
2. 确认相机和选框后点击 **移动并抓取**。等弹窗提示吸附及抬升完成后点 **挂起**。此时保留吸附，窗口完成清理后恢复底盘驱动。若导航此前已放行，桌面核对同一 Mux 及停车代数后交回导航。
3. 再点 **抓取** 可重新打开同一程序，读取已有持物和升降记录。用弹窗内的 **释放** 放下工件；**立即停止** 中断动作并尝试关泵。异常退出或立即停止会保留导航的停车状态。

空载也可挂起。执行中的动作与未确认的吸附或升降恢复需要先在窗口处理。退出候选后用 `"$BASE/run" status`、`"$BASE/run" rtk` 返回现场稳定发布，独立视觉入口为 `"$BASE/run" shell rosrun slicer_visual_grasp run.sh --run`。停止占用设备的原窗口后再切换入口。

软件验证随两套候选的 `logs/` 与 `release.json` 保存。实车验收由负责人组织，核对 v1.9 反馈与轮向、实际吸附保持、挂起后导航接管、再打开及释放。停止功能在无负载或受控负载下单独确认。

现场 v1.9 的历史架空四轮等速测试通过，车体闭环前进曾检测到右轮短时反向并停车。此次移植对齐配套轮位、极性和版本，闭环反向现象仍需先在架空条件下复核。详见现场发布的 `logs/DEPLOYMENT.md`。
