# 视觉抓取三按钮 · 2026-11-21

- 从 `40c3c27` 在独立工作树及 Catkin 目录开发。原车端检出已有无 RTK 速度修改和 `.vscode/`。当前安装仍指向 v1.6 工作区，底盘 v1.7 烧写见独立交接。
- 界面只保留“移动并抓取”“释放”“立即停止”。用 `rosrun slicer_visual_grasp run.sh --run` 启用动作。右键可微调并保存红点。保留用户原点 `[389, 375]`。
- 抓取以固定红点为吸嘴原点，沿用单帧目标和底盘反馈。停稳并释放底盘串口后才开泵；以新鲜本次泵状态开始下降，确认吸附后回中。当前窗口记录指令时长 `t`。释放先确认关泵，随后按记录时长回升。立即停止取消运动并独立请求关泵。
- 现场将 `grasp.max_lower_s` 暂设 10 秒。下降超时或反馈中断回中、请求关泵，已下放的时间仍可在本窗口用于释放回升。升降使用原有方向和 2100/900/1500 µs。运行测试期间导航占用 C30D，测试与预览不打开该串口。

操作与参数见 [视觉抓取说明](../../src/slicer_visual_grasp/README.md)。
